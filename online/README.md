# Speaking Studio 在线版源码

这是与本地版配套的Sites/Vinext在线版本。手机登录后可访问，电脑不必开机。D1保存元数据，R2保存音频，平台提供登录和所有者访问控制。

公开源码只包含合成题包（private-bank.json在本目录也是合成示例），不包含作者的完整题库、个人数据或生产站点身份。部署自己的实例时需通过Sites创建自己的私人站点并填入独立project_id，不能复用他人的站点身份。

npm ci安装开发依赖，npm test运行接口检查。按照Sites标准流程生成D1迁移、构建、打包和部署。模板脚本保留了提供方的许可文件。未经实际验证，不宣称真实手机录音或在线转写已经验收。

本地版仍在上一级目录运行；本目录是在线部署源码，不替换本地data目录。原有本地录音可导出完整备份后，在自己的在线版合并恢复。
